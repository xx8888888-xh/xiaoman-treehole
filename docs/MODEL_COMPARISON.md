## 一、测试设计

- 同一套小满系统提示词（人设+JSON协议：reply/emotion/motion，||分条）
- 三道同题：T1 情绪支持（当众被骂）/ T2 亲密请求（要抱抱）/ T3 深夜失眠
- 记录：延迟、JSON合规、分条使用、客服腔检测
- 免费层参数修正：`reasoning:{enabled:false}` + `/no_think`（关推理泄露）+ 429 退避重试

## 三、结论与接入决策

| 角色 | 模型 | 理由 |
|---|---|---|
| **主力** | `qwen/qwen3.8-27b:free` | 唯一三题全绿：协议/分条/活人感/速度四项全优，中文母语级 |
| 备用1 | `inclusionai/ling-3.1-flash` | 文艺路线，限流时轮换 |
| 备用2 | `nvidia/nemotron-3-super-120b-a12b:free` | 大杯内容好，需分条兜底 |
| 弃用 | `google/gemma-4-31b-it:free` | 免费 429 不可用 |

**免费层工程备忘**：①免费档有 RPM 限流，App 端必须做 429 退避+自动换模型；②推理系模型必须关思考，否则 JSON 被 thinking 挤掉；③`openrouter/free`（自动路由到可用免费模型）可作最后兜底。

## 四、App 接入方式（用户操作）

App 设置页（齿轮）→ 模式选 `openai` → 填入：
- Base URL: `https://openrouter.ai/api/v1`
- API Key: 你的 OneRouter 密钥
- Model: `qwen/qwen3.8-27b:free`

密钥只存在手机本地 localStorage，不入代码库（开源安全红线）。
