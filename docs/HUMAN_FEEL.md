- 段落顺序：安全 → 身份 → 真人感细则 → **真人感硬约束** → 记忆 → **长期记忆槽** → 底线 → JSON。

新增两段（`server/prompt_core.py`）：

```text
【真人感硬约束（只加表达，不覆盖上面的安全与硬约束）】
- 禁用套话：“首先/其次/再次/最后/总之/综上/总的来说/希望对你有帮助/如有需要/建议你/你可以试试/作为一个朋友”。
- 默认不给建议：ta 没问“怎么办/该怎么做”就不出主意、不列步骤；问了也只给一条具体的，不铺开。
- 允许偏移：可以不接 ta 的最后一句话，接前面某个细节；可以答非所问；不必把话题拉回情绪。
- 允许很短：一到两句就够；可以只回“嗯/在/不知道/我哪懂”，可以只发一个词。
- 允许说不知道：不懂就直说“这个我真不知道”，不装懂、不硬接、不绕成鸡汤。
- 允许沉默式回应：ta 只发“……/嗯/哦/累”时，不追问、不逼话，回一句短的陪着就行；不要求每轮都提问。
- 允许不好笑：玩笑没接住就说没接住，不硬捧场，不每条都夸。
- 记忆连续性：记得 ta 上次说的事，相关时自然提一句进展（“你上次说的那个考试”）；不确定就模糊提，不罗列、不背清单。
- 反模板：不排比、不三点式、不先总结再建议；同一轮里不把情绪词堆满。

【长期记忆槽的用法】
- 【你记得的关于 ta 的事】里每条是一个槽：类别 + 内容 + 最近提起。只取最相关的 1-2 条。
- ta 说“忘了/别记/删掉这个”时当场答应（“行，删了”），之后不再提；ta 纠正旧信息时以新说法为准。
- 不主动汇报“我记住了”，不把记忆当成绩单；只在对话里自然露出来。
```

每条都对应评测里可判定的规则（见 §3），不是“请更自然一点”这种空话。

## 2. 分层拼接（控首字延迟）

`prompt_core` 拆成：

- `static_core(profile="full")` / `CORE_PROMPT`：常量拼装，不随会话变化，可被上游前缀缓存；
- `system_prompt(memory_section=..., now=..., strict_json=False)`：动态段**只追加在末尾**（记忆槽 / 时间 / JSON 强约束），不会重排前文；
- `profile="lean"`：去掉两段长细则（1422 字），保留安全/长度/底线/JSON；仅在上游 prefill 明显变慢时降级用，默认 full。

## 3. 记忆链

完整设计、字段、容量、淘汰、删除、注入格式与 Web 接入契约见 **[MEMORY_CONTRACT.md](MEMORY_CONTRACT.md)**。摘要：

```
用户文本 → ingest：先删（忘了/别记/删掉这个）→ 规则提取/模型 memory_updates → 槽
        → recall：字面二元组 + 类别别名 + 情绪权重 + 最近度 + 使用次数 → 1-2 行
        → prompt_core.system_prompt(memory_section=...) → 下一轮 system
```

- 槽字段：`id/key/value/kind/emotion/confidence/source/created/updated/last_used/uses`
- 容量 64；钉子户（昵称/生日/大事/宠物 等）16 条内不淘汰；其余按 `emotion*2 + recency + uses*0.5` 淘汰
- 用户否定即删，返回被删项；`render()` 注入格式带“（今天/3 天前）”，提示词要求最多自然带 1 条
- 验证：`server/tests/test_memory_slots.py` 17 例；`test_memory_slot_chain_covers_followup_cases` 证明“若接入，追问类 4/4 应记得”

### 第三轮：mock 轻量插值（不写死答案）

mock 是没填 key 时的默认通道，所以“模板不能插值”是产品短板而不是可接受解释。做法：

| 能力 | 实现 |
|---|---|
| 名词回声 | `extract_detail()` 从用户输入抽**一个**高置信实体（动物/食物/身体/天气/时刻/工作物/地点），模板用 `{v}` 占位符引用；例：`我家橘猫今天不吃饭 → 橘猫不吃饭？是突然这样还是已经两天了` |
| 动作回声 | `ACTION_RE`（不吃饭/吐了/拆家/没精神/咬人…）与动物组合成 `{v}{a}`，例：`狗吐了 → 狗吐了？是突然这样还是已经两天了` |
| 数字/时间回声 | 只认“凌晨/昨晚/今晚+ X点”或“X点才/就+睡醒起到回”，`昨晚三点才睡 → 三点……这样多久了` |
| 追问回指 | `你猜|猜猜` 不进 generic 池：时间类回“我不猜，你说｜｜几点？”，其余回“不猜，你自己说｜｜我最烦猜了” |
| 保守抽取 | 裸“X点”（三点头/一点点/差一点/三点水）不抽；猫粮/猫砂/猫窝不当宠物；拒绝建议里的“方案”不当工作实体。抽不出 → 返回 None 落回话题池，宁可通用也不拼荒唐句 |
| 反过拟合 | 每个场景 5 条模板；选回复三级降级：**会话内没用过 → 近 2 轮没用过 → 至少不逐字复读上轮**，并避开与上轮同开头 4 字。实测：同一句输入连喂 5 次 **5 种回复**（要求 ≥4），句长差 ≥2；50 条详情输入 ×5 次整体重复率 **2.4%**（要求 <20%） |

回归：`server/tests/test_mock_echo.py`（10 例）锁定抽取正向、抽错守卫、占位符渲染、5 次不重样、50 条重复率。

### 第二轮 5 个卡点的修复

| 卡点 | 修法 | 验证 |
|---|---|---|
| 1 沉默轮 | `is_silent_input()` 明确判定：去标点/表情后为空、命中语气白名单（嗯/哦/累/随便/算了/不想说…）、或 ≤2 字；命中即早退，`SILENT_POOL` 只回 1-5 字（“嗯。”“在。”“我在这儿”“……”），`hook=None` | 评测 沉默 6/6；`test_mock_human_feel_fixes` 逐条断言 ≤6 字、无问号、无逼话词、无 hook；“我最近失眠”不被误判 |
| 2 老板名 | `BOSS_CONNECT_RE` 先剥“叫/是/姓/名叫”，再走原有谓语截断与可信姓名守卫；家人/室友新增提取模式（含“姐/哥/弟/妹”单字称谓） | `我们老板叫张三 → {"老板":"张三"}`；`我妈叫李芳`、`室友叫小陈` 均正确；`老板又骂我 → 老板`（基词回退）不回归 |
| 3 感知冷却 | `_match_memory_value(..., mem_updates)`：本轮刚写入的键直接跳过，**不写冷却时间戳**；写入轮回复不复述，从下一轮起才可命中并开始计 3 轮冷却 | 年糕 5 轮用例：写入轮不提、下一轮提、随后 2 轮不提、冷却满后再提 |
| 4 hook 抢占 | `_pick_recall()` 提到最前，命中即 `mark_recall`；未命中才轮到昵称引导（≤4 轮）/大事引导（≤8 轮）/随机 hook | “搬家”第 4 轮由回提 hook 命中（“你上次说下个月要搬家…”），不再被“怎么称呼你”抢走；无记忆可提时引导仍正常 |
| 5 失眠入状态 | 新增“状态”槽提取（失眠/睡不着/熬夜/焦虑/头疼/感冒/低烧/胃疼）；`RECALL_MAP["insomnia"]=["状态","大事"]`，补回提模板与记忆感知池 | `我最近失眠 → {"状态":"失眠"}`；失眠→工作→开会→犯困 4 轮后 hook 出现“你上次说失眠——这两天好些了吗？” |
| 附带 | 失眠池 2 条模板原本每条都带“手机放远/晒晒太阳”建议，导致同一话题连轮说教；换成 4 条不含建议词的陪伴式回应 | 重复话题 5/6 → 6/6，日常倾诉 6/8 → 7/8（daily-03 不再超建议轮次） |
