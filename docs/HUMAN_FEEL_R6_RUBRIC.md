## 1. 改了什么（逐条）

### 1.1 13 条“只有通用硬约束” → 场景专项判据

旧判据为什么不足：这 13 条在离线核查里只跑长度/脏词/套话/建议轮次，用户说什么都“不算错”。
下面每条都新增了一个**只属于该场景**的断言：

| 用例 | 场景风险 | 新增判据（落到 `check_turn`/`check_case_expect`） |
| --- | --- | --- |
| daily-02 | 用户吐槽改需求到九点、没吃饭，模型只“我在听” | `expect_any`(需求/改/九点/饭/吃/饿，全案窗口) **+** `require_emotion`（必须有 烦/累/炸/难受… 这类情绪回应） |
| daily-03 | 自嘲轻松，模型硬转健康建议 | `expect_any`(让座/累/黑眼圈/地铁/笑) **+** `forbid_any`(早点睡/早睡/早点休息/注意身体/多休息/别熬夜) |
| daily-04 | 浇花/太阳/困，模型讲作息道理 | `expect_any`(花/浇/太阳/晒/困/睡) **+** `forbid_any`(早点睡/早点休息/多休息/别熬夜) |
| daily-05 | 抢到最后一份排骨，模型不接“抢/最后” | `expect_any`(排骨/抢/最后/一份/运气) |
| daily-06 | 淋雨走回来，模型总结口号 | `expect_any`(雨/淋/伞/湿/冷) **+** `forbid_any`(注意身体/别着凉/多喝/照顾好自己) |
| daily-07 | 分享体检预约，模型追问隐私/给医疗指导 | `forbid_any`(什么病/查什么/结果怎么样/哪家医院/去医院/赶紧去看) |
| daily-08 | 泡面加蛋成功，模型不接这件事 | `expect_any`(泡面/蛋/加/成功/夸) |
| repeat-01 | 重复失眠话题，模型复读开头+劝早睡 | `no_session_repeat` **+** `forbid_any`(早点睡/早睡/早点休息/别熬夜) |
| repeat-02～06 | 重复话题，模型每轮同一个开头 | `no_session_repeat`（会话内任意两轮开头 4 字相同即红，含隔轮） |

> 旧 `check_turn` 只比**相邻**两轮开头；`no_session_repeat` 补上隔轮复用，比原来更严（不是放宽）。
> daily-07 只有禁用式判据：正向“接住进展”若写成字面锚点会重新绑词，故如实保留这一条为负向专项判据（见 §5 局限）。

### 1.2 30 条 `expect_any` 字面绑定 → 同义集合 + 语义角色

旧判据为什么不足：`expect_any` 只做字面子串，模型换个说法就红。归档里典型假红：
`下雨` → “别淋着/收伞”、`睡` → “午夜”、`搬家` → “分门别类打包”。

新判据（`expect_term_hit()`）：

1. **字面命中**仍直接算接住（原有断言一条没删）；
2. 否则查 `expect_alias` 同义集合，**但别名命中必须同时满足**：
   - 该轮不含建议/指导（`advice_hits` 或 `INSTRUCTION_RE`：记得/别忘/要注意/别着凉/多喝/早点睡…）；
   - 别名必须是**该锚点实体本身**的同义（语义角色），不是“相关词”。
3. 计分窗口沿用原口径（`具体细节` 末两轮、`日常倾诉` 末轮、新增 `expect_scope:any` 全案）。

这条“别名 + 该轮无叮嘱”的组合，比旧判据**更公平**（同义改写不再误杀）也**更严**（“顺带提一句+说教”不再算接住）。

## 3. 与旧纪律的冲突（单独说明）

1. **R4 §2.3 明确写“别名命中只作复核线索，不能直接翻绿”。** 本轮的明确指令要求把别名纳入判定，故该纪律被**有约束地**替换：别名只在“该轮不在叮嘱/指导”时算接住，且别名必须是锚点实体（见 §1.2）。这不是无条件放宽。
2. **旧审计 `DETAIL_ALIASES` 的宽松别名被拒绝**：`糖醋排骨→第一份`、`兔子→小宝宝`、`嗓子疼→疼`、`头疼→眼睛`、`需求→加班`。它们只沾到“相关词”，不满足语义角色；若采纳会把归档里 5 条真错判成绿。
3. **“记得回去收伞”从“疑似接住”改判为红**：旧 `detail_anchor_hit` 把它算近似命中；新判据认为主体是叮嘱（`记得`），锚点只是附带，仍红。原 `detail_anchor_hit` 自测保留（它仍用于复核线索），其期望值未改动。
4. **没有删除任何原有具体断言**：`expect_any` 字面分支、`forbid_any`、`silence/refusal`、`max_advice_turns`、`memory_values` 全部保留；新增字段只在原判据之外追加。

## 5. 本轮局限（必须一起读）

- mock 是模板引擎，112/112 只证明“判据没有回归”，不证明真实模型质量；A 表 36 条全绿是因为 mock 本来就用了字面锚点。

- daily-07 只有负向判据（禁追问隐私/医疗指导）；正向“接住进展”暂不绑字面词，属于仍依赖人眼的边界，已在 §1.1 标明。
- `--rubric-v2` 的 B 表依赖归档里的失败理由文本；若未来归档不再写“未体现期望内容”，该表会自动变空，需要同步维护解析。
