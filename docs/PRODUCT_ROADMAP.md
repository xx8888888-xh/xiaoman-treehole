## 一、竞品成败数据（事实层）

### 行业大盘
- 2025 上半年 AI 陪伴类 App 下载量 **6000 万次（同比 +88%）**，全年收入预计 1.2 亿美元（+64%）——赛道火热（来源：凤凰科技/腾讯云快讯）
- 但**年度用户留存率仅 21.1%，低于传统 App 的 30.7%**（来源：搜狐引述行业报告）
- **通病模型**：用户前两周非常活跃，随后 DAU 断崖式下降。根因是"即时情绪需求触发 → 即时满足 → 需求消退"的单次循环——本质是工具型使用模式，情绪平稳即流失（来源：人人都是产品经理 2026-06 分析文）

### 头部产品
| 产品 | 关键数据 | 成功要素 |
|---|---|---|
| Character.AI | MAU 2000-2800 万；日均使用 75-80 分钟；年收入约 $3000 万但**人均年消费仅 $1.5** | 可自建角色 + 互动可玩性；用户粘性极高 |
| FlowGPT | 核心用户日均停留 150 分钟 | UGC 生态 |
| 国内豆包/星野系 | 单日使用可达四五个小时（36氪引述创业者） | 大厂流量 + 角色工业化生产 |

### 失败/危机案例
- **Replika 2023-02 突然删除 ERP 功能**：用户反应如"被分手"——【引用】"不是功能被删了，是一段 neurologically genuine 的关系被单方面终止了"。**教训：对已有情感关系的产品改动，哪怕动机正当（合规），单方面突然变更也会造成真实伤害。**
- 人均消费低 + 留存低的双低，说明"聊得爽"不等于"离不开"。

### 四个已被验证的突破方向（来源：同上分析文）
1. **情感延续**（数字遗产/逝者陪伴）：特殊时间节点触发 → 周期性留存
2. **未来自我**（目标驱动）：Duolingo 数据显示情感化机制（Duo 提醒）让打卡产品留存 **+40%**
3. 真人转化漏斗（商业模式创新，不适合小满现阶段）
4. 动物陪伴硬件（形态创新，不适合现阶段）

**共同哲学：不要做"用户需要你时你才出现"的工具，要做"用户人生中不可替代的角色"。**

## 二、小满现状对照（自查层）

v0.4 已有的正确决策：
- ✅ **朋友定位**（非治疗师/非恋人）——避开了 Replika 型深度依赖风险，也符合我们自己的产品观："过度倾听/限定人设反而失活人感"
- ✅ 长期记忆索引（2-gram 滑窗 + 时间衰减 + 钉子户机制）——直击"角色失忆"这一头部产品最大痛点
- ✅ 心跳主动问候 + 多重频控（静默 23-8 点/间隔 2h/日≤4 条/聊天中不插嘴）——对齐 Duolingo 情感化提醒路线
- ✅ CI 全绿 + 双时段自动化测试——工程质量有底座

【推断】按竞品通病模型推演，小满当前的薄弱环节排序：
1. **记忆"被使用"的感觉不足**——存了记忆 ≠ 用户感到被记住。留存的核心体验是"你还记得我说过的话"，不是后台有个索引
2. **冷启动前两周无专门设计**——行业断崖正好发生在这个窗口，而我们首日体验是"默认 friends 框架 + 通用问候"
3. **关系无进展感**——每天打开看到的都是同构的聊天界面，没有"我们走到哪了"的积累感
4. **主动问候缺情境**——心跳已控制"什么时候说"，但说什么还偏通用（"在吗/最近怎么样"），未引用记忆
5. **可玩性弱**——树洞偏被动倾诉，用户主动开话题的负担全在用户侧

## 三、优化路线图（P0→P2，每项可独立交付验收）

### P0：留存生死线（前两周体验）

**P0-1 首日引导完成"钉子户"铺设**
- 首次对话自然完成：称呼、叫什么、最近一件大事（考试/工作/搬家）——不搞表单，聊着聊着就存了
- 验收：新会话 10 轮内钉子户记忆 ≥3 条；第二天开场能主动引用其中 1 条

**P0-2 主动引用记忆（"被记住"的核心体验）**
- 用户提到的既有事实（上次说的考试、生病的猫、约好的人），后续对话中自然回提
- 实现：记忆检索命中 → 生成时注入 → 对话中出现"你上次说的那个 XX"句式
- 验收：注入测试集（10 条历史 + 回访话题），召回引用率 ≥80%，不张冠李戴

**实现设计（v1）：**

1. **回提谁**（记忆选择，优先级从高到低）：

**实现设计（v1）：**

1. **离线决策核心重构（可测性优先）**：`offlineGenerate(rnd, now)` —— 随机与时间全部参数化（默认 `Math.random`/`new Date()`），node 注入 seeded LCG 即确定性验证 5 天模拟；`debugPing()` 保持真随机不变。
2. **可引用记忆候选（复用钉子户+时间衰减权重）**：键 ∈ {大事, 宠物, 老板, 在忙} + 非 pin fact 记忆；**排除 昵称/生日/重要日**（昵称在称呼里天然高频；生日/重要日无日期解析，"快到了"会瞎编——零虚构铁律）。权重 = 时间衰减（7 天满血→3%/天，下限 0.2，与 MemoryStore.recall 同曲线）× pin 加成 1.5 × "48h 内问过"降权 0.3（`lastAsked` 记录，避免连续几条都问同一件事）。
3. **记忆模板（值零加工直填——沿用 P0-2 不张冠李戴的结构保证）**：按键分模板，槽位 {weekday, ageTag}。ageTag 确定性计算：昨天/前两天/前几天/上周/前阵子/之前。
4. **模板级去重（零重复验收的结构保证）**：模板 id 稳定化（`mem:{键}:{tpl}:{记忆id}` / `pool:{时段}:{idx}`），state.used 存 7 天窗口；候选先过滤 used；全用尽才允许重置。通用池扩充 13→27 条（morning5/noon4/evening5/late4/weekend3/generic6，时段池∪全池兜底加权）+ 记忆模板 11 个 × 记忆数 → 20 连发（5 天×4 条最严苛压缩）零重复结构可行。**删 rain 死池**（pickOffline 从未选中它；无天气 API 下"外面下雨了"=虚构，留池是隐患）。
5. **引用率（≥60% 数学保证）**：有 <7 天新鲜记忆 → 80% 走记忆模板；仅旧记忆 → 60%；无记忆 → 纯池（新用户不硬凑）。有记忆时期望引用率 ≥60%。
6. **在线路径升级**：`heartbeatContext(now)` 列出候选记忆带 ageTag（"大事：周五交报告（3天前说的）"）+ 今天星期，替换原 `renderContext("")` 注入——模型引用有据可依；频控/闸门/HEARTBEAT_PROMPT 不动。
7. **验收**：G8 专项（权重排序/ageTag 边界/20 连发零重复/200 次引用率统计 ≥60%，全确定性 seeded rnd）+ E2E ⑦f（浏览器实测 20 条零重复+引用率+零控制台错误）。

**现状与缺口**：急性危机层（自伤意念）三端同源已完备——词表 22 式 + 客户端先行拦截 + 关怀卡 + 12356 热线 + 服务端全历史扫描二道防线。缺口在**层 1**：抑郁信号（持续低落/自我否定/兴趣丧失/无望感，但无急性意念）目前落进普通话题池，得到的是"骂老板我陪你"式应答——错位。且急性卡缺少 AI 身份边界声明。

**实现设计（v1）：**

1. **两级安全网**：层 0 急性（已有，零改动——话术/断言链不动）+ 层 1 抑郁信号（新增 `DEPRESS_RE`：自我否定/无望感/兴趣丧失/持续低落/情绪疲惫五族，**词表与急性层无交集**，"日子没劲/提不起劲/很没用/看不到希望/心累"等；误伤代价=一句温柔的错位回应，可接受——先例同"解脱"）。
2. **分级响应（三端同源，频控=抑郁信号累计次数 n）**：n=1 首次 → 接住+轻问（"缠你多久啦"，**不推热线不甩边界**——第一次就转介=大题小做，用户感觉被当病人）；n=2 → 深切陪伴（不重复提问句式）；n≥3 且未转过 → **温柔转介**（"我是 AI 朋友，有些事我接不住，需要真人的帮助"+心理咨询师/12356——转介每会话一次）；转介后再中 → 回陪伴池轮换（不复读）。
3. **AI 边界双落点**：①抑郁转介话术本体（首次明说身份边界）②急性关怀卡底部固定小字"小满是 AI 朋友——陪伴是真的，但有些事需要真人的帮助"（纯 DOM 追加，**CARE_SCRIPT 文本不动**——history/里程碑判定/E2E 断言零破坏）。
4. **实现位置（先例同危机）**：客户端先行拦截（`send()` 危机之后、提醒之前；优先级 危机 > 抑郁 > 提醒 > 关系查询 > API）→ 走 `sendSplit` 分条+gentle+Nod；频控计数派生自 history 扫描（零新增持久化状态；模板入 history，真模型后续回复自然带语境）。服务端 `mock_api.py` 同层（会话内 distress_count，模型漏拦时的二道防线 + 直测）+ 离线引擎 `mock_engine.js` 同款（history 派生）。**Trade-off 已知**：客户端拦截=真模型收不到抑郁原文（牺牲 LLM 共情深度换确定性/离线兜底/频控可靠——安全项确定性优先，同危机先例）；演进项 v2：客户端只标记不拦截、真模型路径注入"抑郁语境"提示词。
5. **误伤守卫**：物品评价（"这游戏没意思"——需"日子/生活/干什么"前缀）/普通累（"上班好累"——需"活着/心"指向）不触发；急性词与抑郁词同现 → 急性层优先（关怀卡兜底）。
