## 2026-10-11（下午）· P2-4 Q 版悬浮挂件（用户 08:55 指令）

**贡献**：给小满做出"退出后还在"的陪伴形态——主界面收起后，她变成缩在屏幕边上的 Q 版小挂件；提醒从这里说，偶尔摆摆手。

- **资源最省路线（用户要求"能省就省、复用现成模型"的落地）**：不建第二个 Pixi 应用、不下载任何新模型——`body.widget-mode` 下主 UI 隐藏，**同一个 Live2D canvas** 经 CSS 缩成 84px 圆形贴右下角，`stage.js` 新增 `focusHead()` 聚焦头部特写（Q 版观感=同一模型的缩小特写），眨眼/呼吸 idle 保活——挂件里是"活的"，不是截图。展开时 `restoreView()` 精确还原收起前的视图。
- **提醒从挂件说**：零新链路——提醒到期 → Heartbeat.tick → pushFn → sendSplit（TTS 照播），挂件模式下同一消息经 `Widget.notify()` 从挂件上方气泡弹出 + **摆手**（复用现有 Shake 动作组）。首跑抓到一个体验 bug：气泡取了末段口语（"我说到做到的，别赖"）而提醒内容在首段——修正为提醒类取信息段。
- **偶尔摆摆手**：挂件模式独立低频随机动作（5-10 分钟一次，40% 概率配极短气泡"还在哦/戳我回聊天"），频率远低于心跳闲聊——不打扰优先（负面清单红线）。
- **产物**：`web/js/widget.js`（新，~100 行）、stage.js（focusHead/restoreView + 挂件模式 resize 重聚焦）、app.js（按钮/气泡/摆手接线）、index.html（收起按钮+气泡容器）、style.css（挂件模式布局+气泡样式）、E2E ⑦i 4 点。
- **验证**：E2E ⑦i（收起贴边圆形/挂件播报提醒+气泡/摆手链路/展开还原/零控制台错误）+ 全套回归（见 DEVLOG 当轮记录）。

## 2026-10-11（上午）· P2-1 小满的自我叙事（进行中→收口）

**贡献**：给小满装上"朋友圈"——它不再是只会问"你怎么样"的应答机器，开始像朋友一样主动分享自己的近况。

- **为什么这样设计**：竞品数据（Character.AI 日均 75 分钟）证明"可玩性/活人感"是留存的另一半拼图；P1-2 心跳解决了"关心你"，P2-1 补上"分享我"——朋友感=两个视角都有。
- **零虚构铁律的延伸**：用户数据（考试、猫）绝不能编，但小满自己的叙事若瞎编（"外面下雨了"）同样破功——P1-2 删 rain 死池就是这个教训。解法是**三层全部真实可验**：
  - A 层·数据观察：新建 `stats.js`（~100 行）真实统计"哈哈"次数/深夜来访/说话天数/招牌 emoji，数字直填（"你跟我说过的'哈哈'都有 7 次了"——7 是真的数出来的）
  - B 层·真实动作：6 条模板全部是小满在屏幕世界**真做得到**的事（翻聊天记录/整理记忆抽屉/听自己的 TTS 语音），不断言用户世界
  - C 层·翻记录见记忆：视角反转（"我看到{大事}那页，折了个角" vs P1-2 的"问你进展"）
- **工程保障**：记忆路径概率未动 → P1-2 引用率 ≥60% 结构保证不退化（G9-5 实测 16/20）；频控闸门零改动（P2-1 原文要求）；门槛防尬（haha≥3 才开口，2 次就说"你爱哈哈"很怪）
- **产物**：`web/js/stats.js`（新）、`web/js/heartbeat.js`（SELF 三层候选+生成分支+在线素材注入）、`web/js/app.js`（bump 挂钩）、`web/index.html`（加载 stats.js）、G9 专项 22 点
- **验证**：G9 22/22 + 记忆全套 106/106 全绿（含 B 层"不虚构用户世界"断言词自动审计）

## 工程方法沉淀（贯穿全程）

- **零虚构铁律**：用户数据绝不能编——天数/日期/统计全部来自真实数据源，无数据优雅降级不硬凑（先例：关系问答、月度回放、自我叙事门槛）
- **闭环定义**：实现→测试→文档→提交→CI 绿→main 合并、三方 ref 一致才算完
- **挂账收口法**：会话被切断的 WIP 不是废稿——验证→补缺口→回归→提交（P0-1/P1-1/P1-3 三度验证）
- **测试先行取舍**：决策核心参数化（rnd/now 可注入）→ 确定性验证；浏览器 E2E 补真实链路
