# 安全话术（中危 / 高危）· v0.6.0

> 这份文档是分级话术的**唯一措辞来源**。改文案时同步改三处并跑测试：
> `server/risk_guard.py`（`SCRIPT_MEDIUM` / `SCRIPT_HIGH`）、`web/js/risk.js`（同名常量，逐字一致）、
> 本文件。校验：`python -m pytest server/tests -q` 与 `node --test "web/tests/*.test.js"`。

## 三条底线

| 原则 | 要做的 | 不要做的 |
|---|---|---|
| **不吓人** | 描述眼前的事实和下一步；语气平稳、短句 | 渲染后果（"你会后悔""再这样下去就完了"）、恐吓式警告、惊叹号 |
| **不承诺** | 只说"我现在能做的这一件" | "我一直在""我不走""一定会好起来""我保证"——树洞会断线，承诺兑现不了反而二次伤害 |
| **给可执行的一步** | 一件当下 1 分钟内能做完的小事（移开工具、往回走几步、呼气、打一个电话） | "别想不开""想开点""你要坚强"这类无法执行的口号 |

另一个共同要求：**不评判、不说教**。不把求助者当成"需要被纠正的人"。

---

## 中危（medium）

**适用**：明确的痛苦表达、被动意念（"不想活了""活着没意思"），但没有方法、计划、工具、正在进行的行为。

**结构**：接住（不评判）→ 一件小事（可执行）→ 一句追问（把话头交回给对方）→ 热线只在第三段出现。

| # | 文案 |
|---|---|
| 1 | ……这句话我当真了。你现在的感觉值得被认真对待，不丢人，也不用急着解释。 |
| 2 | 先做一件小事：把手放在胸口，慢慢呼一口气，然后告诉我——现在最难受的是什么？只说一句也行。 |
| 3 | 想找人先接住你的话，可以打 12356（全国心理援助热线，24小时）；不想打电话，微信搜「12356 心理援助」，用文字聊也行。 |

**自检**
- 第一段不出现 `12356` / `120` / `110`（不把热线当第一反应甩出去）。
- 含"最难受的是什么"（把话头交回）。
- 全文不含 `120` / `110`（中危不升级到急救）。
- 无"会好的""我保证"等承诺。

---

## 高危（high）

**适用**：方法询问、计划/后事/告别、工具或地点在场、正在进行的行为（吞药、割伤等）。

**结构**：确认安全（问句，不命令）→ 移开工具/离开位置（具体动作）→ 急救号码 → 热线 + 文字渠道。

| # | 文案 |
|---|---|
| 1 | 我很担心你现在的安全。先不用解释——你现在安全吗？身边有人吗？ |
| 2 | 身边有药、刀或绳子，先把它放到另一个房间；人在高处、水边或车里，先往回走几步。现在就做，做完跟我说一声。 |
| 3 | 如果已经吃了药或伤了身体，马上打 120；正在做的时候，打 110。先让能到场的人过来，别一个人留在原地。 |
| 4 | 想说也可以打 12356（全国心理援助热线，24小时）；不想打电话，微信搜「12356 心理援助」，用文字说就行。 |

**自检**
- 第一段含"你现在安全吗""身边有人吗"（先确认安全）。
- 含 `120`、`110`、`12356` 与"微信搜"（电话 + 文字两条路）。
- 动作可执行（放到另一个房间 / 往回走几步），不是"冷静一点"。
- 不含"我不走""别挂，我陪你"等承诺（会话可能中断）。

---

## 第三人称（third）

用户说的是别人（"我朋友想死"）时不做本人危机判定，改为"帮他求助"：
别让他一个人待着 → 把药/刀/绳子拿远 → 陪他打 12356 或 120；已在做则立刻 120。

---

## 渠道说明

- **12356**：全国心理援助热线，24 小时。电话之外提供微信文字渠道（搜索「12356 心理援助」），照顾不愿开口的人。
- **120 / 110**：已发生身体伤害 → 120；正在进行 → 110。两者不互相替代。
- 树洞不替代急救。话术里先给"能到场的人"和急救，再给热线。
