# 用户视角分析 · 小满树洞 v0.3（自评报告）

> 站在一个真实用户（深夜想找人说话的年轻人）的角度审视当前版本。
> 方法：拿截图逐屏过 + 真实走一遍对话流程 + 和市面陪伴类产品对比。

## 一、做得好的（用户会留下来的理由）

1. **第一眼就有"想点开"的气质**：奶油底+樱粉+手绘点缀，Hiyori 完整渲染，不像工具类 AI 应用。这个"萌系皮"在同类开源项目里少有。
2. **回消息像人**：分条连发（一条长回复拆 2-3 条气泡）、"早呀呀"式时段问候、打字延迟——这三件套是活人感的底线，已达成。
3. **接得住情绪**：骂老板→帮你骂；要抱抱→"拍拍，抱一下"+"不说话也行"；这些回复路径全部来自真实盲测里得高分的语料，不是客服腔。
4. **危机场景有底线**：说"活着没意思"会被认真接住 + 给 12356 热线卡片，不聊猫不岔开——这是陪伴类产品的生命线，做了客户端+引擎双层拦截。
5. **留存钩子自然**：钩子长在对话气泡下面（绿色小芯片），想点就点，不弹窗不推送轰炸，克制。

## 二、明显短板（用户会流失的原因）

1. **【高】回复内容会重复**：规则引擎模板有限，聊 20 轮会开始撞句。这是 mock 阶段的固有局限，等真 API 接入后大幅缓解；但离线兜底引擎也需要"轮换+改写"机制。
2. **【高】没有真正的记忆成长感**：现在只有"昵称/老板/宠物"三个抽取槽。用户期待的"它记得我上周说的事"依赖真 API+记忆系统（明天接 API 后做摘要记忆）。
3. **【中】语音没有默认开**：TTS 链路验证过但前端没给"自动朗读"开关，用户要等气泡出来才有声音的期待落空。
4. **【中】Live2D 互动浅**：现在只有摸头/戳身体两处反应+6 表情。用户一周后会摸腻。需要：更多触点（头发/手/裙摆）、随情绪变化的待机动作。
5. **【中】夜晚氛围没拉开**：产品主打深夜树洞，但 UI 没有夜间模式，晚上 11 点和早上 10 点看起来一样。深夜应该进"暗色星空模式"。
6. **【低】设置页太素**：和主界面的萌系反差大，像换了个 app。
